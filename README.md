# CHEATCAM v4.0

## IP Camera Security Testing Framework

Advanced surveillance system security assessment tool for authorized penetration testing and security research.

## Features

- Multi-brand camera detection (Hikvision, Dahua, Axis, TP-Link, Samsung, Sony)
- MAC address fingerprinting
- Port scanning
- API endpoint discovery
- Default credential testing
- Snapshot capture
- RTSP stream hijacking
- ONVIF service exploitation
- Firmware vulnerability testing (CVE-2021-36260, CVE-2021-33044)
- Full camera control (view stream, reboot)

cd CHEATCAM
